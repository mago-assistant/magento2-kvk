# Mago Assistant skill: KVK company lookup

A [Mago Assistant](https://github.com/mago-assistant/mago) skill for Magento 2 that answers "which industry is this customer in?" in the admin chat. It looks up a Dutch BV or NV in the free KVK Open Dataset Basis Bedrijfsgegevens and returns its industry (SBI activities), legal form and status.

It sits next to [mago-assistant/vies](https://github.com/mago-assistant/vies): VIES validates the VAT number and returns the registered name, this skill tells you what the company does.

Work in progress: the module itself is under review in a pull request.
